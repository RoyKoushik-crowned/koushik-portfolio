Backend / Infrastructure · 2026

Async Product Photo Processing at Scale

A personal project solving a realistic e-commerce problem: keep uploads fast even when image processing is slow, by taking the slow work off the request path entirely.

  • Built an asynchronous FastAPI, Redis, and Pillow producer/queue/consumer pipeline so CPU-bound resize-and-watermark work never blocks the upload response.
  • Containerized services with multi-stage Docker builds and production-oriented runtime configuration.
  • Deployed to Kubernetes with liveness/readiness probes, ConfigMaps and Secrets, plus HorizontalPodAutoscaling that scales worker pods 4→15 under load.
  • Documented a production-hardening roadmap covering event-driven autoscaling, object storage, CI/CD and observability.
  • FastAPI
  • Redis
  • Pillow
  • Docker
  • Kubernetes
  • HPA

LLM / GTM Engineering · 2026

AI-Agent-Driven Outbound Growth Pipeline

An independent project designing and running a full LLM-assisted growth pipeline end-to-end, twice, with every send confirmed landing in a sandboxed inbox.

  • Ran a two-stage pipeline: a zero-API-call heuristic prefilter followed by Gemini qualification against a written rubric, with verdicts logged.
  • Sourced and processed 225 candidate leads across two runs, reducing the candidate set before spending LLM quota and qualifying the remaining leads for outreach.
  • Diagnosed and fixed production issues around exception handling, rate-limit cooldowns and batch references, protected by a mandatory dry-run gate.
  • Built contextualized outbound email sequencing with delivery safeguards and completed both runs with zero failed sends.
