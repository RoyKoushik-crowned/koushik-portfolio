Backend / Infrastructure · 2026

Async Product Photo Processing at Scale

A personal project solving a realistic e-commerce problem: keep uploads fast even when image processing is slow, by taking the slow work off the request path entirely.

  • Built an asynchronous pipeline (FastAPI, Redis, Pillow) using a producer/queue/consumer pattern, so CPU-bound resize-and-watermark work never blocks the upload response.
  • Containerized every service with multi-stage Docker builds, running all containers as non-root.
  • Deployed to Kubernetes with liveness/readiness probes, ConfigMaps and Secrets for config, and a HorizontalPodAutoscaler that scaled worker pods 4→15 under load testing.
  • Documented a production-hardening roadmap — event-driven autoscaling via KEDA, object storage, CI/CD, observability — covering what an MVP still needs for real production use.

LLM / GTM Engineering

AI-Agent-Driven Outbound Growth Pipeline

An independent project designing and running a full LLM-assisted growth pipeline end-to-end, twice, with every send confirmed landing in a sandboxed inbox — never a real recipient.

  • Ran a two-stage pipeline: a zero-API-call heuristic prefilter, then an LLM qualification pass (Google Gemini) scoring each candidate against a written rubric, every verdict logged.
  • Sourced and processed 225 candidate leads across two runs via the GitHub search API, cutting the set by ~40% before spending any LLM quota, then qualifying 8–19% of the remainder.
  • Diagnosed and fixed three real production bugs: a mismatched exception path that crashed a batch instead of logging one bad record, a rate-limit retry that ignored the API's own cooldown, and a hardcoded reference that would have silently sent the wrong batch — caught by a mandatory dry-run gate before it shipped.
  • Built automated email sequencing against a transactional-email API (Mailtrap) with synthetic-alias routing; both runs completed with zero failed sends.
  • Used LangGraph/LangChain to contextualize the outbound emails, and authored a measurement page quantifying the full funnel plus a "what breaks at 10x volume" scaling analysis.
  • Gemini API
  • GitHub API
  • LangGraph
  • Mailtrap
  • Vercel
